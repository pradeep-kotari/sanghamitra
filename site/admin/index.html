What this is for

You already keep Sanghamitra going on WhatsApp, at the hall, and on YouTube. This site does not replace that. It is a page you can send people, so sanghamitra.org is not a parking page and a flyer can point somewhere real.

  1. Edit what changes. Phone, events, photos — save here. You do not need us for a new sitting.
  2. Give. Paste a Zelle name or number, Venmo, or PayPal.me under Donate only if you actually accept gifts that way. Blank means the public page will not invent a method.
  3. 5 September. Copy invite / WhatsApp friends if you want a second channel besides the group you already have. I’m coming is optional — a name list, not a gate.
  4. Notes from the site land under From the site. WhatsApp is still the faster door, as it always was.
